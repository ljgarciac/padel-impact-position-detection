# IBM Plex

Tipografía oficial de Carbon Design System. Se incluye en el repositorio a propósito:
esta es una aplicación local y debe renderizar igual sin conexión a internet.

- `IBMPlexSans-Regular.woff2` (400), `IBMPlexSans-SemiBold.woff2` (600)
- `IBMPlexMono-Regular.woff2` (400), para todas las cifras

Son 179 KB en total. Convertidas desde los OTF oficiales que distribuye Fedora
(`ibm-plex-sans-fonts`, `ibm-plex-mono-fonts`) con `fonttools`.
